# 基于 Linux C/S 架构的远程设备状态监控系统

## 📖 项目描述
基于 C/S 架构的轻量级设备状态监控系统。服务端部署于 Linux 主机，支持客户端接入并上报设备运行状态（设备 ID、CPU 使用率、内存使用率、时间戳）。全程使用 C 语言原生 API 与 POSIX 接口实现，无第三方库依赖，适用于资源受限的嵌入式设备管理场景。

## 🛠️ 技术栈
- **核心语言**：C 语言
- **网络通信**：Linux Socket, TCP/IP
- **系统接口**：POSIX 接口
- **编译构建**：Makefile

## 💡 核心功能实现
- **网络通信框架**：基于 Socket API 搭建 TCP 服务端，完成 `socket` / `bind` / `listen` / `accept` 全流程。设置了 `SO_REUSEADDR` 解决服务器重启时的端口占用问题，并实现了客户端断开后的检测与 `fd` 清理。
- **设备状态上报**：定义了 `DeviceStatus` 设备状态结构体。客户端采集状态后通过 `send()` 上报，服务端 `recv` 解析并打印。为保证两端内存字节级一致，使用了 `__attribute__((packed))` 消除结构体内存对齐填充。
- **工程化构建**：编写 Makefile 文件，实现项目的一键编译（`make`）与清理（`make clean`）。

## 🚀 如何编译与运行
1. 在 Linux 终端执行 `make` 进行编译。
2. 运行服务端：`./server`
3. 运行客户端：`./client`（支持通过 `./client 1002` 传入参数模拟多设备）
